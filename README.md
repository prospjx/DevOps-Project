This project is still just in development. It is a FastAPI project that aims to be a to-do list. 
It uses FastAPI, Python, Postgresql, Docker, Uvicorn
Main.py is the base of the application, where it shows all the routes of the application
Database.py is where the sqlaclchemy engine is created from.
Config.py is env is loaded from, but is it not being used for now.
tasks.py is where the tasks column and detailes are specified and created.
Dockerfile and compose.yaml are the docker components to build the image.
