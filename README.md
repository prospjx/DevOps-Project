# Task Management API

A FastAPI-based Task Management API built as a hands-on DevOps learning project and cloud learning project. The application uses Python API, PostgreSQL for data persistence, Docker Compose orchestration, Terraform infrastructure provisioning, and automated CI checks.

# Overview

This project includes:

FastAPI REST API for task management
PostgreSQL database for persistence
Docker Compose setup for local development
Terraform configuration for infrastructure provisioning
Automated testing with Pytest
Linting and formatting checks with Ruff and Black
Swagger/OpenAPI documentation generated by FastAPI

## Running Locally

### Prerequisites

- Python 3.10+
- Docker Deskstop
- Docker Compose
- Git
- Terraform

### 1. Clone the repository

```bash
git clone https://github.com/prospjx/DevOps-Project.git
cd DevOps-Project
```

### 2. Configure environment variables

Create a `.env` file based on `.env.example`.

```env
APP_NAME=Task Management API
APP_VERSION=1.0.0
ENVIRONMENT=development
DATABASE_URL=postgresql://postgres:password123@localhost:5432/tasksdb
```

> Do not commit your `.env` file to GitHub.

### 3. Start the application

```bash
docker compose -f docker/compose.yaml up --build
```
This will start:

the FastAPI application
the PostgreSQL container


The API will be available at:

```text
http://localhost:8000
```

Swagger documentation:

```text
http://localhost:8000/docs
```
Health Check:

```text
http://localhost:8000/health
```

Task Check:

```text
http://localhost:8000/tasks
```

# API Endpoints:
GET /

Returns: 

{
  "first": "Task Management API",
  "version": "1.0.0",
  "environment": "development"
}

Based on you env file. 

Health Check

GET /health

Returns:

{
  "status": "healthy",
  "database": "connected"
}

Tasks
Create a task

{
  "title": "Finish project proposal",
  "description": "Write the final draft before Friday",
  "due": "2026-08-20"
}

Response: 

{
  "id": 1,
  "title": "Finish project proposal",
  "description": "Write the final draft before Friday",
  "due": "2026-08-20",
  "completed": false
}

GET /tasks/

Returns a list of task objects.

## Code Quality

Check formatting with Black:

```bash
black --check .
```

Run Ruff:

```bash
ruff check .
```

## CI/CD

GitHub Actions automatically:

1. Checks code formatting with Black.
2. Runs Ruff linting.
3. Runs Pytest.
4. Builds the Docker image.
5. Pushes the image to the configured container registry.
